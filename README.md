# Generative AI Prompts

A collection of generative AI prompts designed to improve productivity and support learning.

These prompts cover everyday tasks, research, writing, information synthesis, and automated workflows. They can be adapted to different AI tools and personal needs.

## Daily Digest

[DailyDigestPrompt_YS.txt](DailyDigestPrompt_YS.txt) — A prompt for creating a personalized daily digest covering important emails, local weather, recent cancer research, broader scientific perspectives, and major news. 
It prioritizes time-sensitive information and includes source links in a concise, easy-to-read format.
